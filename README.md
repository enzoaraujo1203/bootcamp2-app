# Painel do Clima

## Autor
Enzo Reis Araujo — Matrícula 22553166

## Descrição
Uma aplicação web interativa para consultar a previsão do tempo de qualquer cidade no mundo em tempo real. É útil para quem deseja verificar a temperatura atual, condições do tempo e velocidade do vento de forma simples e rápida.

## API utilizada
- **Open-Meteo API**: https://open-meteo.com/
- **Endpoints consumidos:**
  - Geocoding API: `https://geocoding-api.open-meteo.com/v1/search`
  - Forecast API: `https://api.open-meteo.com/v1/forecast`

## Funcionalidades
- Pesquisa de previsão do tempo por nome de cidade
- Exibição de localidade (cidade, estado/região e país)
- Exibição de temperatura atual em graus Celsius (°C)
- Exibição da condição do clima (céu limpo, nublado, chuva, etc.) com ícone/emoji
- Exibição da velocidade do vento em km/h
- Pesquisa facilitada ao pressionar a tecla "Enter"
- Tratamento amigável de erros para cidades não encontradas ou falhas na rede
